## Key points

- The exercise: design a hotel website in Canva with three pages: title, features and contact.
- Title page: a background image, a serif title and a sans-serif subtitle, aligned and spaced with care.
- Features page: images and headings first, body text second; same style as the title page.
- Contact page: the same style and alignment, a modern image and a titled text block.
- Publish the design as a web page and ask for feedback. Daily UI gives daily prompts and Collect UI gives inspiration.

## What we gained

- We applied color, type, UI and UX in one small project.
- We know where to find prompts (Daily UI) and examples (Collect UI) to keep practicing.
