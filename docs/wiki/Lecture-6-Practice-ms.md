*Tangkapan skrin: Collect UI ([sumber](https://collectui.com/))*

Daily UI ([dailyui.co](https://www.dailyui.co/)) tiada tangkapan skrin di sini kerana animasi halamannya tidak dipaparkan dalam tangkapan headless.

## Perkara utama

- Latihan: reka laman web hotel dalam Canva dengan tiga halaman: tajuk, ciri dan hubungi.
- Halaman tajuk: imej latar, tajuk serif dan sari kata sans-serif, dijajarkan dan diberi jarak dengan teliti.
- Halaman ciri: imej dan tajuk dahulu, teks badan kemudian; gaya sama seperti halaman tajuk.
- Halaman hubungi: gaya dan penjajaran yang sama, imej moden dan blok teks bertajuk.
- Terbitkan reka bentuk sebagai halaman web dan minta maklum balas. Daily UI memberi tugasan harian dan Collect UI memberi inspirasi.

## Apa yang kami peroleh

- Kami menggunakan warna, tipografi, UI dan UX dalam satu projek kecil.
- Kami tahu di mana mencari tugasan (Daily UI) dan contoh (Collect UI) untuk terus berlatih.
