## Key points

- First impressions are fast: a website is judged like a job interview.
- Good design raises the perceived value of a product. Penny Juice shows this: the 2002 site has clashing colors and mixed fonts, the rebrand and the current site use one color scheme and better type.
- The four pillars: Color Theory, Typography, User Interface (UI) design and User Experience (UX) design.

## What we gained

- We can explain why design matters as much as function.
- We can name the four pillars and use them as a checklist for any site.
